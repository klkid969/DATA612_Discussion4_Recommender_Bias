# DATA 612 - Research Discussion Assignment 4

This repository contains my Week 4 research discussion for DATA 612.

The discussion examines recommender systems, algorithmic bias, and user choice by connecting the assigned readings with personal experiences using online shopping, music streaming, travel booking, and food delivery platforms.

Topics include:

- Social influence bias
- User control and transparency
- Algorithmic recommendations
- Business objectives versus user experience
- Real-world examples from everyday technology
